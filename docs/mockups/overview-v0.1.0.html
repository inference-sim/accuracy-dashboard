Numbers are illustrative placeholders for layout only. Scope: single_turn sweeps with ≥3 concurrencies. No quality filtering — we do not drop “outliers” or “bad-silicon” points; every measured point is scored and shown (report, don't assert). Multi-node is the one scope control: it's a toggle (off by default, since a multi-node run exercises cross-node collectives), and when on, BLIS replays those deployments with the correct multi-node scenario (node count, fabric, and pp/tp/ep placement written into the scenario the harness feeds blis replay). “same-points Δ vs previous snapshot” appears on hover per cell. A failed or partial nightly run publishes nothing and leaves the previous snapshot in place.
